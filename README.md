# 瓏昇廠房機電報價比較

靜態網站，直接由 GitHub Pages 提供，路徑 `/longsheng-mep-comparison/`。

## 使用

以 HTTP 伺服器開啟本目錄（例如 `python3 -m http.server`）。網頁會載入 `data.json`。

提供分類與關鍵字篩選、單價／複價比較、價差排序、明細與原 PDF 頁碼、CSV 匯出。

## 資料來源與核對

來源依序為得江山 1150921、立東（東舜）1151029、大展 1151110 報價，PDF 位於 `sources/`。

- 對齊 882 項，原始明細筆數為 880 / 881 / 881。
- 三家各五大類明細加總，均與原報價首頁金額完全相符。
- 立東後 29 頁的品牌備註，依頁面與表格列位置對回前 29 頁。
- 工程大類、細項分類、設備群組、項次及規格共同核對，避免不同配電盤同名零件混比。
- 排除得江山 PDF 的隱藏編輯文字；大展「器具」子標題不視為新的盤體。
- 128 項數量不同；61 項含未列價／未列項；99 項原表複價與數量乘單價相差超過 1 元（可能含原表顯示精度差異），保留原表複價。
- 未列價不補零；不同數量不計複價高低；單價比較仍需確認品牌與範圍。
- 立東首頁所列 5% 代管費計費基礎待確認，未自行加到總價。
